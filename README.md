# 风栖小镇 · Yua World

基于 Three.js 的自然风格乡间小镇。人物参照提供的图片，以程序化三维几何体制作浅紫双侧发束、遮眼刘海、金色眼睛、黑金发饰和蓝黑金服装，支持四肢、头发与裙摆动画，并带有虹膜纹理、眨眼、独立手指、发束层次、饰品和服装缝线。全部场景与人物均由代码生成，无须下载模型或图片。

## 本地运行

需要 Node.js 22 或更新版本，无 npm 安装依赖。

```sh
npm run dev
```

在浏览器打开终端显示的端口（默认 5173）。Three.js 固定为 0.180.0，通过 `cdn.jsdelivr.net` 加载，需要浏览器联网并支持 WebGL。请通过 HTTP 服务访问，不能直接双击 HTML 文件。

## 操作

- 左下摇杆：相对当前视角移动，推动幅度控制步速，松手停止。
- 右半屏拖动：旋转及俯仰视角，可与左手移动同时操作。
- 右上角：春、夏、秋、冬及晴天、雨天、雪天切换；浏览器会保留选择。
- 小地图：实时显示人物位置与朝向，点击可展开完整地图，地图中标记「我的家」、学校、医院、超市等。使用关闭按钮、Escape 或点击遮罩关闭大地图；查看地图时移动输入暂停。
- 桌面端也可使用鼠标拖动摇杆与视角，或使用 WASD / 方向键移动、Shift 奔跑。

界面包含天气、四季控件、小地图和无文字操作区。360×360 的小镇采用自然布局，沿曲线路线安排聚落，石板路、土路、环形步道、木桥和踏石各具特色。蜿蜒河流和两处池塘可观赏游鱼，通过三座木桥可到达对岸。人物会避开建筑、树干、喷泉与水域。

场景包含钟楼、花房、咖啡屋、面包房、图书小屋、风车、水车磨坊、集市、凉亭、神社、蘑菇屋、遗迹、拱门、井、手推车和篱笆等。植物涵盖阔叶树、松树、白桦、花树、垂柳，以及花丛、草簇、蘑菇、灌木、芦苇和睡莲。鹿、狐狸、兔子、野猪、鸭子、鱼、蝴蝶、蜻蜓、鸟和甲虫具有各自的移动或振翅动画。新增带开放院门、围栏、花园和阳台的两层、三层住宅，以及学校、医院、超市和邮局。人物身高约 2.2 个场景单位，住宅与公共建筑的门洞高度不低于 2.8，避免人物与房屋失衡。静态物件和人物的刚性细节按空间或材质合批，远处动物及场景按距离隐藏。

河床实际低于水面，平地比水面高约 3 个场景单位，河岸、池塘边缘、桥头路堤与外围丘陵均具有真实坡度。人物、相机和陆地动物跟随地形高度，桥梁横跨低处的河面。道路按统一网格合并交叉路面，不再叠放重合的道路面与铺石，辅以深度偏移减少闪烁。

主角有一处专属两层住宅，并从自家前院出发。可通过开放院门和正门进入客厅、餐厨区，沿 24 级楼梯登上二楼，探索卧室、书桌阅读区和阳台，再沿原路下楼。进入室内时屋顶、上层楼板或近侧墙面会按楼层自动隐藏，保留碰撞。院内包含带锦鲤的鱼池、凉亭、花圃、猫狗宠物、双人秋千、单杠、双杠、扭腰盘与漫步机。住宅位置固定，地图中以金色房屋图标显示。

四季改变植被、地面、河水与屋顶配色；天气改变光照与雾气，雨雪会跟随人物。

## 检查与构建

```sh
npm test
npm run build
node scripts/serve.mjs dist
```

测试覆盖移动速度、碰撞、滑动、边界、河流与池塘阻挡、三座桥通行以及曲线路线布局、住宅两层与楼梯高度、小地图坐标和朝向。`dist/` 为可发布的静态站点，所有本地资源使用相对路径，兼容仓库 Pages 子路径。

## 发布到 GitHub Pages

1. 将代码推送到仓库的 `main` 分支。
2. 在 GitHub 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. `Deploy village to GitHub Pages` 工作流将运行测试、构建并发布；也可在 Actions 页面手动运行。
4. 工作流成功后，使用部署任务输出的 Pages 地址访问。首次发布可能需要几分钟。

没有后端、数据库或密钥要求。GitHub Actions 使用内置 `GITHUB_TOKEN`，无需手动添加 token。工作流必须成功运行才代表已发布；仅提交配置不会自动启用仓库的 Pages 设置。
